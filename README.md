# product-catalog

Interactive product catalog for the Unit 2 lab activity, built with semantic HTML5, CSS Flexbox/Grid and vanilla JavaScript.

**Live site:** https://dybdev.github.io/product-catalog/

## Features
- Product grid rendered from a JavaScript array
- Category filter buttons (All, Laptops, Phones, Accessories)
- Contact form with validation (name, email, message) and alerts
- Form submission using the Fetch API
- Responsive layout with media queries
